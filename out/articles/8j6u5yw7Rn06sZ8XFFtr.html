[Tutorial] Firebase Full-Text Search

Last Modified 09/09/2022

    While making the website written in React and hosted on Firebase Database, I recognized that I wanted a search function for my articles page. Being a lazy and cheap developer, I wanted a fast, easy, and financially responsible solution; I stumbled upon Algolia, a search platform (search engine + infrastructure) with built in Firebase extension and a free tier. What does that mean? I don’t need to write and deploy more than 20 lines of code, and pay for hosting and using the search engine.

    To get started with Algolia, go to Algolia.com  and make a free tier account. Then, create a new application and index. The implementation can be separated into two parts – Firebase DB connection with Algolia and React connection with Algolia.

 

Firebase DB + Algolia

    Thankfully for us, Algolia has an extension for Firebase which will save us some time. Head to the Firebase extension page and install the Algolia extension. The Algolia extension creates a Firebase function that pushes desired information to the Algolia server once there are changes to Firebase DB, where the information is indexed and made searchable. 

    You can control what information is searchable in the extension configuration page. The Collection Path is the collection in Firestore DB that you want the search function to be implemented. Firestore Function will be triggered once there are changes in the collection. Indexable Fields are field names in Firestore that you want the search to be conducted on, hence are the only fields that are sent to Algolia. 

    If you want to sanitize your data before sending it to Algolia, you can create a Firebase function and put the name of the function in Firebase config Transform Function Name. The Firebase Function should be https callable (functions.https.onCall) and the output should match the input. Consider deploying functions similar to the code below:

 

const functions = require("firebase-functions");

const transform = (payload) => {
    return {
        ...payload,
        "paragraph": payload.paragraph.replace(/\n/gm, “ “)
    };
};
 
exports.algoliaSanitize = functions.https.onCall((payload) => {
    const transformedData = transform(payload);
    return transformedData;
});

 

React + Algolia

Install two dependencies:

 

npm install algoliasearch react-instantsearch-hooks-web

 

Create an Algolia config file:

 

import algoliasearch from 'algoliasearch';
 
export const searchClient = algoliasearch('your-application-id', 'your-search-api-code');

 

Then, you need to add an Algolia provider that encapsulates where you want to do search. Notice that you need to declare your Algolia index name.

 

import { searchClient } from ‘../api/algolia-config.js’
 
<InstantSearch searchClient={searchClient} indexName="article">
     {/* My custom search UI or Algoria provided widget */}
</InstantSearch>

 

I personally dislike the UI that Algoria provides, hence I am making my own search widget. I am going to start with the search bar using the useSearchBox hook. The refine parameter allows you to set the search input. Take a look at the example below (I am using MUI).

 

import { useSearchBox } from 'react-instantsearch-hooks-web';

export default function SearchBar(props) {
    const { refine } = useSearchBox(props);
    const [text, setText] = useState("")
    useEffect(() => {
        refine(text)
    }, [text, refine])
    return (
        <TextField label="Search in Articles" variant="outlined" value={text}
                 onChange={(event) => { setText(event.target.value) }}
                     InputProps={(text.length!==0)? {
                          endAdornment:
                               <IconButton onClick={()=>{setText("")}}>
                                   <CloseIcon />
                               </IconButton>}:{}
        } />
    )
}

 

To display the search results, use the useHits hook.

 
import { useHits } from 'react-instantsearch-hooks-web';
 
export default function ArticleSearch(props) {
    const [article, setArticle] = useState(Array(6).fill(null))
    const { hits } = useHits(props);
 
    useEffect(()=>{
        setArticle(hits)
    }, [hits])
 
return (
            article.map((doc) => <ArticleCard doc={doc}/>)
        )
}

 

Now you have an instant search function on your website!
